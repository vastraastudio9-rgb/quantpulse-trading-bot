# QuantPulse deploy

## Live website (Grok hosting)

1. Open the QuantPulse Grok Build chat.
2. Click **Publish**.
3. Copy the `*.grok.me` link.
4. Optional: Custom domain → paste DNS records at your registrar.

That is the production site. No extra hosting purchase.

## This GitHub branch

`grok-desk` holds the Grok-built web desk under `/grok-desk` so `main` (Next.js + Python engine) stays intact.

Download zip: Code → grok-desk branch → Download ZIP.

## Telegram + live trading

Configure inside the published desk (Brokers). Tokens stay on your device unless you add your own secrets host.
